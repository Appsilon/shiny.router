# Package index

## Main router functions

- [`router_ui()`](https://appsilon.github.io/shiny.router/reference/router_ui.md)
  : Create router UI
- [`router_server()`](https://appsilon.github.io/shiny.router/reference/router_server.md)
  : Create router pages server callback
- [`make_router()`](https://appsilon.github.io/shiny.router/reference/make_router.md)
  : \[Deprecated\] Creates router.
- [`route()`](https://appsilon.github.io/shiny.router/reference/route.md)
  : Create single route configuration.
- [`route_link()`](https://appsilon.github.io/shiny.router/reference/route_link.md)
  : Route link
- [`get_query_param()`](https://appsilon.github.io/shiny.router/reference/get_query_param.md)
  : Get Query Parameters
- [`change_page()`](https://appsilon.github.io/shiny.router/reference/change_page.md)
  : Change the currently displayed page.
- [`parse_url_path()`](https://appsilon.github.io/shiny.router/reference/parse_url_path.md)
  : Parse url and build GET parameters list
